# Isoba · движок

Считает все карточки приложения Isoba из открытых официальных рядов (ФРС, Минтруд, Минфин, Бюро переписи США, BIS, МВФ и др.).
Раз в день GitHub Actions (`.github/workflows/isoba-data.yml`) скачивает входы, проверяет движок и коммитит
`isoba/data.json` и `isoba/history.json`. GitHub Pages отдаёт их приложению:

    https://nickarstrong.github.io/lokio-apps/isoba/data.json
    https://nickarstrong.github.io/lokio-apps/isoba/history.json

Каждый коммит — публичная запись с датой того, что показывал индекс; задним числом её не изменить.

## Запуск на своём компьютере

    pip install pandas numpy xlrd
    python fetch.py      # входы → data/ (FRED без ключа + индекс GPR)
    python isoba.py      # → ../data.json и ../history.json
    python verify.py     # VERIFY GREEN — можно коммитить

`sources.csv` — единственный список входов: ряд, файл, источник, частота, задержка публикации в днях, лицензия, где используется.

## Правила расчёта

- **Без будущего.** Каждый вход — перцентиль 0–100 своей истории до этого дня. Ряд виден в день публикации
  (дата наблюдения + `lag_days`). `verify.py` пересчитывает всё на рядах, обрезанных по 31.12.2019, и требует
  совпадения с полным расчётом в каждом дне до этой даты.
- **Детерминизм.** Одни входы — один выход байт в байт. Время запуска не участвует.
- **Сглаживание.** Все приборы — недельное (EWM, 10 дней): один шумный день не меняет зону.
- **Зона** считается по показанному целому числу.
- Nasdaq и даты рецессий NBER нужны только чтобы посчитать «как часто бывало» для «Что впереди». В приложение не идут.

| Прибор | Из чего | Зоны |
|---|---|---|
| DSI 0–100 | F3 доллар 40 % · F1 ставки 20 % · F7 потоки EM 15 % · F2 риск 10 % · F6 геополитика 5 % · сырьё обратно (100 − F4) 10 % | слабый < 35 · нейтрально < 65 · сильный |
| Кризисометр 0–100 | 4 лампы: кредит и фондирование, банки режут кредиты, пособия, экономика | спокойно < 25 · умеренно < 50 · напряжение < 75 · стресс |
| Риск вершины 0–100 | аналог Bear Market Risk Indicator Goldman Sachs: безработица, заводы, базовая инфляция, кривая, капитализация / ВВП | спокойно < 60 · поздний цикл < 75 · перегрев |
| Риск рецессии 0–100 | кривая 10 лет − 3 мес., опрос банков, разрешения на стройку, пособия, реальная ставка | низкий < 50 · средний < 65 · высокий |

## data.json — контракт с приложением (схема v3, ≈10 КБ)

Ключи — на английском, текст на 22 языках — в приложении.

| Ключ | Что | Карточки |
|---|---|---|
| `asof` | последний рыночный день в данных: «Данные на 15 октября» | шапка |
| `dsi` | `v`, `zone` weak/neutral/strong, `since` (в зоне с), `w1`/`m1` (неделю и месяц назад), `parts` {F: [значение, вес, вклад]} — вклады в сумме = `v` | Индекс доллара · DSI |
| `crisis` | `v`, `zone` calm/moderate/tension/stress, `since`, `w1`, `m1`, `lamps` {лампа: [перцентиль, горит]} | Кризисометр |
| `ahead.top` | `v`, `zone` calm/late/overheat, `now`/`usual` — % случаев «Nasdaq ниже на 20 %+ за 12 мес.» в этой зоне / в любой (дни у максимума рынка, с 1995), `zones`, `lamps` | Что впереди |
| `ahead.rec` | `v`, `zone` low/medium/high, `now`/`usual` — % случаев «рецессия США началась за 12 мес.» (с 1990), `zones`, `lamps` | Что впереди |
| `context` | фоновые лампы без веса: нефть, доллар, кредит Китая | Почему? |
| `changes` | 1–3 строки за неделю, вид `k`: `zone` {card, from, to, v0, v1} · `move` {card, v0, v1} · `rate` {v0, v1, f, df} · `lamp` {id, on, v} · `filter` {f, v0, v1} · `steady` {card, v, m1 \| since, lit} | Что изменилось |
| `filters` | F1…F8: `v`, `w1`, `m1`, `in` {вход: перцентиль} | Восемь фильтров, 8 фильтров по одному |
| `fed` | `usd` {v, q1} — доллар ФРС (broad), `rate` {v, q1} — ставка ФРС, %, `crisis` {v, m1}; q1 — 3 мес. назад | Ряды ФРС |
| `recent` | `d0`, `n` = 130 и массивы dsi, crisis, top, rec, F1…F8, usd, rate — рабочие дни (пн–пт) подряд с `d0` | мини-графики |
| `data_through` | ряд → дата последнего наблюдения | О протоколе |
| `sources` | ряд → лицензия | О протоколе |

Лампа горит с 80-го перцентиля. Ключи ламп: `crisis.*`, `top.*`, `rec.*`, `context.*` — те же, что в `history.json`.

## history.json (≈880 КБ, ≈100 КБ сжатым)

`{v, asof, d0: "1990-01-01", n, days: "Mon-Fri", dsi, crisis, top, rec, F1…F8, lamps: {"группа.лампа": […]}}` —
каждый массив: одно целое 0–100 (или `null`) на рабочий день подряд с `d0`. DSI и F1–F8 — с 2006 года.
Карточки «История по дням» и «Разбор любого дня»; приложение качает файл, только когда их открывают.
